# PrimeLab

## About
AI/ML learning repo following the Apna College Prime Batch course.

## Workflow
- Always work on the `dev` branch
- Push to `main` only via PR after review
- Follow the course pace — don't install libraries or jump ahead unless asked

## How to assist
- Act as an assistant professor — explain concepts clearly and simply
- Help write, debug, and run code from course lectures
- Give practice problems when asked
- Keep code beginner-friendly with clear variable names
